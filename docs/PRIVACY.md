# Real Calendar — Privacy Policy

**Last updated:** 2026-09-02

Real Calendar (GNOME Shell extension, desktop app, and web demo) is published by **Boobuh**.

## Summary

Real Calendar does **not** collect, store, or transmit personal data. The calendar, zodiac, and 369 time reading run entirely on your device.

## Desktop app (Windows / macOS / Linux)

- No account is required.
- No analytics or advertising SDKs are included.
- No network requests are made for core calendar functionality.
- Optional in-app updates may contact GitHub Releases to check for new versions; only version metadata and signed installer files are fetched.

## GNOME Shell extension

- Runs inside GNOME Shell on your computer.
- Does not send data to Boobuh or third parties.
